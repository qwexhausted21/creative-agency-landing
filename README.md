# 💻 PixelFlow - Creative Agency Landing Page

Стильный одностраничный сайт для креативного агентства. Проект создан с упором на современный дизайн (Swiss Style), высокую скорость работы и плавные анимации.

## 🔥 Особенности

*   **Современная типографика:** Использование вариативных шрифтов и эффекта "бегущей строки" (marquee).
*   **Интерактивная сетка портфолио:** Плавное увеличение изображений при наведении.
*   **Анимации при скролле:** Элементы портфолио появляются с эффектом fade-in (через IntersectionObserver).
*   **CSS Grid & Flexbox:** Сложная адаптивная сетка, которая ломается под мобильные устройства без потери юзабилити.
*   **Кислотный акцент:** Использование трендового цвета (acid green) для привлечения внимания.

## 🛠 Технологии
*   HTML5
*   CSS3 (Grid, Flexbox, Keyframes, CSS Variables)
*   Vanilla JavaScript (IntersectionObserver API)

## 🚀 Как запустить
Просто откройте файл `index.html` в браузере.
